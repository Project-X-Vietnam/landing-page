## What Is This?

PJX Case Trainer is an AI-powered coach that trains your structured thinking for case interviews — without giving you the answers.

You activate it by loading two files into your AI platform of choice:

1. **The System Prompt** — tells the AI how to behave as your coach
2. **The Case Hub** — the library of practice scenarios you draw from

Both files are available directly on the **[Project X Vietnam landing page](https://projectxvietnam.org)**. You do not need to write or configure anything from scratch.

> **The goal is not to finish fast. The goal is to train how you think.**

Go to claude.ai. In the left sidebar, click Projects → Create Project. Name it exactly:
`PJX Case Trainer`

### Step 2  Paste the System Prompt
Inside the project, find Project Instructions (the settings/configuration area). Paste the full system prompt you received from PJX into that field, then save.

Inside your PJX Case Trainer project, click New Chat.

## Quick Reference — What to Do Each Session

Regardless of your platform, every practice session follows the same pattern:

```
1. Open a NEW chat inside your PJX Case Trainer project/Gem
2. Type a case request (e.g., "Give me a Product case")
3. Work through the 5 steps in order:
      Define → Decompose → Hypothesize → Analyze → Recommend
4. Type: "Please evaluate my performance across all 5 dimensions now."
5. Read your debrief — identify your lowest dimension
6. Note the "One thing to try" drill for your next session
7. Close the chat — start a new one for your next case
```

## Tips for Getting the Most Out of Each Session

**Before you type anything:**
- Write your answer in your notepad first, then paste it into the chat. This forces you to think before you commit.
- Re-read the scenario twice before beginning the Define step. Identify what information is given and what is missing.

**During the session:**
- Do not ask the coach for hints. If you are stuck, state your current thinking and ask the coach to ask you a clarifying question.
- Treat every pushback as useful information, not a mistake to fix quickly. The coach pushes back because your reasoning has a gap — find it.
- Do not rush the Recommend step. Candidates consistently under-invest here after working hard on the earlier steps.

**After the session:**
- Do not skip the debrief. Reading a score without reading the evidence notes defeats the purpose.
- Focus your next session on your single lowest-scoring dimension — not on trying to improve everything at once.
- Vary your case categories across sessions. If you only practice Product cases, your other dimensions will plateau.

> 💡 **Reminder:** The goal of this trainer is not to finish fast. It is to build the habit of structured, evidence-based thinking that will carry into real interviews.

## Troubleshooting

| Problem | Likely cause | What to do |
|---|---|---|
| The coach gives me a direct answer | System Prompt was modified or not pasted correctly | Re-paste the System Prompt exactly as provided from the landing page |
| The coach jumps between steps randomly | Session context is corrupted from a previous run | Start a new chat — never continue a previous session with a new case |
| The evaluation doesn't produce a score table | Evaluation was triggered before Step 5.5 was complete | Complete all 5 steps, then trigger evaluation |
| The coach doesn't reference the Case Hub | Case Hub file was not uploaded, or wrong file was uploaded | Re-upload the Case Hub file from the PJX landing page |
| ChatGPT ignores the instructions mid-session | Context window limit reached in a long session | Start a new chat and resume from your current step |
| Gemini / Claude responds in a different language | Platform language setting override | Add "Always respond in English" to the first message of each session |
