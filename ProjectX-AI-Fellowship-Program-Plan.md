# Project X Vietnam — AI-for-Impact Fellowship

**A Claude Corps–style program, operated by Project X Vietnam**
*Program plan & host profile guide — v1.0 (July 2026)*

---

## 1. Concept in one line

Project X trains early-career AI talent and places them inside Vietnamese mission-driven organizations for a fixed term to build working AI tools that cut staff hours and strengthen programs. Frontier labs (Anthropic / OpenAI) supply API credits only — no binding partnership.

## 3. Roles & structure

- **Operator — Project X:** runs the program end to end.
- **Fellows:** trained early-career AI talent, embedded in a host.
- **Hosts:** mission-driven organizations receiving a fellow to solve a problem.
- **Sponsors:** corporates / foundations funding fellow stipends (ESG-aligned).
- **Credit providers:** Anthropic / OpenAI — API access only.
- **Mentors:** existing Project X network, for technical + career support.

---

## 4. Fellow profile

- Early-career (0–2 yrs experience) or strong students; no degree requirement.
- Everyday comfort with AI tools; can prompt, build with an API, run a basic eval.
- Strong communication; works well embedded in a non-technical team.
- Demonstrated drive for social impact.
- Bilingual (VN/EN) strongly preferred for host + donor work.

**Training before placement (base camp):** prompt design, building with Claude/GPT APIs, retrieval (RAG), evaluation, plus a "working inside a nonprofit" module (scoping, stakeholder management, handoff).

---

## 5. Host profile — selection criteria

A host qualifies if it meets **all** of the following:

| Criterion | Requirement |
|---|---|
| **Legal form** | Registered social enterprise, local NGO, foundation, or INGO country office |
| **Size** | ~5–50 staff (enough to supervise, small enough to feel impact) |
| **Location** | Physical/hybrid office in Hanoi, HCMC, or Da Nang (pilot) |
| **Digital baseline** | Uses cloud tools / CRM / some structured data |
| **Sponsor** | A named senior leader who champions the fellowship |
| **Supervisor** | A bilingual or tech-comfortable staff member for day-to-day management |
| **Project** | One concrete, data- or text-heavy workflow to improve |
| **Commitment** | Office space + supervisor time for the full term; a sustainability plan |

**Disqualifiers:** no named supervisor; no concrete workflow ("just make us AI-ready"); fully remote (for pilot); unwilling to give data access; expects a production consumer app.

**Priority sectors:** workforce/vocational training, disability inclusion, anti-trafficking & child protection, education, health, environment/conservation, rural development.

## 7. What fellows build — project archetypes

Almost every host project maps to one of four reusable patterns:

1. **Intake / triage tools** — auto-classify and route incoming beneficiary forms, messages, or applications.
2. **Document → report generators** — turn raw field data / notes into structured donor & M&E reports.
3. **Translation + content adaptation** — consistent VN↔EN for curricula, grants, impact stories, training material.
4. **Knowledge assistant (RAG)** — a chatbot grounded in the org's own manuals/FAQs for staff or beneficiaries.

**Scope rule:** internal, staff-facing, one workflow, a handful of users, real hours saved. Not consumer-scale apps.

## 9. Program model — recommended pilot

| Parameter | Recommendation | Rationale |
|---|---|---|
| **Fellows** | 5–8 | Small, manageable, real signal |
| **Hosts** | 3–4 | Enough variety, not overwhelming |
| **City** | One (Hanoi *or* HCMC) | Concentrate ops + travel |
| **Duration** | 3–6 months, part-time (2–3 days/wk) or stipended full-time | Fundable; fits Project X DNA vs. 12-mo salaried |
| **Funding** | 1–2 sponsors under "AI for Social Impact" | Uses existing corporate relationships |
| **Tooling** | Claude and/or GPT credits | Tooling-agnostic, no lab binding |

**Three phases per placement:** Discover (~15%) → Build (~65%) → Handoff (~20%). Handoff (docs + staff training + sustainability plan) is mandatory.

---

## 10. Funding model

- **Core cost = fellow stipend/salary.** Labs cover credits only, so this is on Project X.
- **Primary source:** existing corporate sponsors (Google, Microsoft, FPT, VNG, Grab, etc.) via ESG/CSR budgets — framed as workforce development **+** social impact.
- **Secondary:** foundation grants, development donors (UNDP, British Council, embassies fund SE/impact work in Vietnam).
- **Per-fellow budget lines:** stipend, credits (lab-provided), device/access, training, program overhead, convening.
- **Host contribution:** in-kind only (office, supervisor time, data access) — keep the barrier low.

---

## 11. Legal, employment & compliance

- **Fellow employment:** define a compliant stipend/contract structure under Vietnamese labor law (Project X as employer, or a partner) — this is CodePath's role in the US model.
- **Foreign funding:** if any lab/foreign money flows as aid, check VUFO/PACCOM foreign non-governmental aid rules; keeping labs as pure credit providers avoids most of this.
- **Data & IP:** host owns everything the fellow builds; sign a short host MOU covering data access, confidentiality (critical for Blue Dragon / CSAGA / health), and IP.
- **Background checks:** required for hosts working with children or vulnerable populations.

---

## 12. Impact measurement

- **Per project:** staff hours saved, cycle-time reduction, tool adoption after handoff.
- **Per fellow:** skills gained, post-program placement/employment.
- **Per host:** tool still in use at +3 / +6 months; new AI workflows adopted.
- **Program:** fellows placed, hosts served, sponsor ROI story (for renewal).
- Keep it lightweight but real — this doubles as the sponsor-renewal case.

## 14. Risks & mitigations

| Risk | Mitigation |
|---|---|
| Can't fund stipends | Anchor to sponsor ESG budgets; start small (5–8 fellows) |
| Weak host pipeline (new sector for us) | Use VUFO/LIN/CSIP as front doors; over-recruit early |
| Hosts scope moonshots | Enforce scope rule; coach during discovery |
| Tools die after handoff | Mandatory handoff phase; +3/+6-mo check-ins |
| Data sensitivity (trafficking/health) | Tight access, MOUs, background checks, restricted projects |
| Fellow ≠ senior engineer | Match capability to project complexity; keep scope internal |
